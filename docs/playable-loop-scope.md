# Playable Loop Scope

The cycle 60 game is a tactical skirmish loop wrapped in persistent character and campaign play.

## Core Loop

1. Launch the packaged app.
2. Select or create characters.
3. Generate or choose a scenario.
4. Deploy characters on the skirmish board.
5. Take turns moving, shooting, reloading, clearing jams, using cover, and resolving wounds.
6. Review dice and result events while playing.
7. Finish the scenario with a clear win/loss result.
8. Apply campaign advancement, recovery, and roster consequences.
9. Save/export characters and campaign state.

## First Release Includes

- Playable skirmish board.
- Character-sheet UI.
- Campaign advancement between skirmishes.
- AI opponent.
- Scenario generator.
- Dice/result log.
- Character save/export.
- Tutorial duel.
- Rule reference overlay.
- Packaged macOS app using SwiftUI, Metal, and C.

## First Release Excludes

- Network multiplayer.
- Full controller-authored campaign editor.
- Mod/plugin system.
- Full visual asset pipeline beyond what is needed for readable play.
- Large-scale battles beyond the skirmish board target.
